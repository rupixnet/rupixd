# Security / Seguridad

## 🇬🇧 Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and click
**Report a vulnerability**. Only the maintainers can see the report.

- We aim to acknowledge it within **72 hours** and to share a first assessment within **7 days**.
- Once it is fixed, we publish what happened in the [CHANGELOG](./CHANGELOG.md) and credit you if you want. We publish our bugs.
- Scope: the node (`rupixd`), the wallet, the miner, the consensus rules (ladder, burns, gems commitment, checkpoints) and the release binaries.

Rupix is on testnet: testnet coins have no value, but a consensus bug found today is one that never reaches mainnet.

## 🇪🇸 Reportar una vulnerabilidad

Por favor **no** abras un issue público para un problema de seguridad.

Repórtalo en privado por GitHub: abre la pestaña **Security** de este repositorio y da clic en
**Report a vulnerability**. Solo los mantenedores ven el reporte.

- Buscamos acusar recibo en **72 horas** y dar una primera evaluación en **7 días**.
- Cuando esté corregido, publicamos lo que pasó en el [CHANGELOG](./CHANGELOG.md) y te damos crédito si quieres. Publicamos nuestros bugs.
- Alcance: el nodo (`rupixd`), la wallet, el minero, las reglas de consenso (escalera, quemas, sello de gemas, checkpoints) y los binarios de cada release.

Rupix está en testnet: las monedas de testnet no tienen valor, pero un bug de consenso encontrado hoy es uno que nunca llega a mainnet.
