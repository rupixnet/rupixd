## Rupix v0.6.9 — Reproducibilidad contra un sistema declarado

**Sin cambio de consenso.** Mismo código de consenso que v0.6.7 (checkpoint #3 compartido con el nodo #2, confirmación externa del #2, `verificar` corregido). **Usa esta; v0.6.7 y v0.6.8 están marcadas «no usar».**

- v0.6.7: los binarios del CI no coincidían con los compilados desde el código, porque el compilador de C del runner de GitHub cambió. v0.6.8 intentó quitar C del todo y no compiló: las firmas (`secp256k1`) y `muhash` son código C. Las dos quedan documentadas tal cual en CHANGELOG.
- v0.6.9: la reproducibilidad se declara contra un sistema concreto y fijo: Linux se compila en Ubuntu 24.04 con Go 1.26.6 y su gcc 13.x, y `tools/verificar-binarios.sh` exige ese mismo sistema antes de comparar. Windows y Mac también en versiones fijas, nunca `latest`.
- Checkpoint #3 (blue 1,987,200), caducidad de la lista en DAA 3,900,000. Actualiza antes del DAA 2,600,000 (~25-oct).

Verifica tu descarga con `SHA256SUMS-<os>.txt` o con `rupixwallet --testnet verificar`.

## Rupix v0.6.9 — Reproducibility against a declared system

**No consensus change.** Same consensus code as v0.6.7 (checkpoint #3 shared with node #2, external confirmation of #2, `verificar` fixed). **Use this one; v0.6.7 and v0.6.8 are marked "do not use".**

- v0.6.7: CI binaries did not match the ones built from source, because GitHub's runner changed its C compiler. v0.6.8 tried to remove C entirely and did not compile: signatures (`secp256k1`) and `muhash` are C code. Both are documented as they happened in CHANGELOG.
- v0.6.9: reproducibility is declared against a concrete, pinned system: Linux is built on Ubuntu 24.04 with Go 1.26.6 and its gcc 13.x, and `tools/verificar-binarios.sh` requires that same system before comparing. Windows and Mac on pinned versions too, never `latest`.
- Checkpoint #3 (blue 1,987,200), list expiry at DAA 3,900,000. Update before DAA 2,600,000 (~Oct 25).

Verify your download with `SHA256SUMS-<os>.txt` or with `rupixwallet --testnet verificar`.
